# Complete-stranger acceptance review

This is a structured self-review in a clean browser using only the interface,
not a claim that independent study participants were recruited. An independent
newcomer's comprehension and first-60-second experience remain for owner review.

| Question | Visible answer / affordance | Review |
|---|---|---|
| What problem is solved? | Opening explains spend on visits that would happen anyway. | Present before the first CTA. |
| Why isn't visit prediction enough? | Interactive hypothetical “Visits anyway” example contrasts response with additional visits. | Both ad-on/off states checked; all three types selectable. |
| What was built and tested? | Study question and four ranking explanations introduce learned strategies compared with random targeting. | Everyday-language names precede model terminology. |
| Where did the data come from? | Corrected Criteo Uplift v2.1 in study; official attribution and dataset link in footer. | Visible, without reading GitHub. |
| What do the large numbers mean? | Exact record count, practice-ground/final-exam split, descriptive-rate bars and count labels. | Counts reconcile; observations are distinguished from estimates. |
| What do model charts mean? | Dot/whisker explanation, named rankings, fixed reach controls, denominator explanation and exact table. | No causal winner label. Mobile-specific SVG dimensions and readable labels. |
| Why retain no targeting? | Decision reveal explains 40 development abstentions, prior freezing and assumption limits. | Positive secondary estimates cannot reselect the policy. |
| How can a team benefit? | Decision conclusion describes fair comparison, transparent sensitivity and evidence-led spending discipline. | No invented financial savings or deployment success. |
| What is hypothetical? | Teaching examples and budget lab label conceptual content, numeric price/value inputs and exploratory arithmetic. | Lab defaults to no targeting; exploratory state cannot change the primary decision. |
| What was not established? | Limitations explain unknown assignment, privacy sampling, no proven optimality or real ROI. | No claim that advertising is ineffective. |
| Where is the methodology? | “The science” chapter, expandable details, case study/model-card/source links. | Direct #science route, navigation and disclosure controls checked. |

Browser evidence covers desktop, tablet and mobile widths, keyboard teaching
interaction, anchor routing, no overflow, public-only resource requests, checksum
verification and exploratory/default budget states. Automated checks do not prove
all-device accessibility or substitute for a formal WCAG or human usability study.
