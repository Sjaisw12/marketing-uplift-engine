## Delivered

A separate static React/TypeScript/Vite application in `web/`, with custom local
CSS, editorial serif typography, warm paper/forest/rust identity, responsive SVG
illustrations, keyboard-operable controls and reduced-motion support. It is not
a Streamlit restyling. Three production dependencies: React, React DOM and decimal.js.

Six chapters: conceptual ad incrementality, the benchmark/practice-ground/final-exam
story, saved model comparisons, the hypothetical Decision Lab, the frozen decision
and reference sensitivity, and expandable technical science/provenance. The no-targeting
recommendation is identified in the opening and never replaced by exploration.

The built `dist/` is independently servable as static files. The private review
package contains source, prebuilt site, 38 real screenshots, member hashes, diff,
validation logs and preview instructions. It is prepared locally, not uploaded.

## Scientific and security verification

The public snapshot is byte-identical to its original approved source:
`358c331d72df76d0ca1e4fddd36c7c35be32b1a0b2dd0ae12949c5967ac46169`.

exact fields, provenance formats, primary recommendation, count reconciliation,
all 1,530 predeclared rows, saved interval ordering and frozen simultaneous-critical
consistency. Tests cover tampering, missing/duplicate/unexpected data, nonfinite
values, unsupported scenarios/reaches and negative/over-budget illustrations.

No intervals or effect estimates are generated by the site. It selects saved
IPW/shared-DR rows at exactly five assumed propensities and five saved reaches.
The full original 765-comparison uncertainty family remains qualified, including
nuisance sensitivity not individually selectable in the UI. Graph axes merely
position saved points; the sensitivity chart has no connecting/smoothed curve.

Financial arithmetic uses 28-digit, half-even decimal operations. Ceiling reach,
eligible-population scaling, negative values and budget rejection match the verified
Python semantics for the site's supported numeric inputs. Large financial labels
stay decimal strings. Conceptual customer types are explicitly invented examples,
not classified real individuals or observed individual treatment effects.
